## Sobre

Desenvolvo software desde 2018 e soluções para clientes desde 2019. Em 2020, fundei a **SoftGestão**, por meio da qual transformei necessidades de negócio em **28 sistemas personalizados para aproximadamente 50 clientes**.

Meu processo de desenvolvimento é **AI-first**: utilizo LLMs como parte central do trabalho para apoiar decomposição de problemas, geração e revisão de código, prototipação, debugging, testes, documentação e evolução incremental.

Este portfólio reúne uma seleção de projetos e experiências desenvolvidos nesse contexto.
